# 恩名手记体验优化清单

这一轮从「录完找文件」「在手表看最近录音」「回顾时核对原话」等任务出发，先走查界面和状态逻辑，再调整交互。[七项行为分析与验收条件](superpowers/plans/2026-11-24-journal-ux-flows.md)记录了改动依据；未做用户访谈或真机易用性测试。

**会议地点**：录音详情与每日回顾共用应用内 MapKit 地图。有精度时用范围圈表示录音开始附近的大致区域；未记录时显示说明。地图不抢列表滚动，也没有跳转到其他 App 的入口。

| 用户任务 | 已实现 |
| --- | --- |
| 同步后确认录音到了 | 可折叠的状态卡区分请求、等待手表和实际收到文件；分页条数不变也能更新。同卡可分别查看手表原音最近入库与 iCloud 同步的时间。 |
| 在 Watch 找刚录完的一段 | 最近五段优先，按时间排列；更多录音、健康和录音设置都有独立入口。在对应录音里看纪要；近期记录转移或清理后仍显示实际状态。 |
| 回顾时核对纪要 | 原文引用按会议折叠，标记仍直接可达。底部仅一个回听控制，显示当前会议与标记或引用时段；原音不可用时仍可阅读引用。 |
| 在分析前确认范围 | 预览归档日期、待整理段数、备份需要和原音去向；确认后新到的录音留待下次。结果按等待手表、备份、网络、配置等原因显示下一步。 |
| 改设置或导出 | 首页优先展示处理方式、录音存储、保留和备份。「不处理」时 Mac 下载紧接模式选项；模型、上传格式和心率阈值在进阶设置。 |
| 按日期找到回顾 | 周回顾显示周一到周日的实际日期；录音时间用录制地时区及当时的 UTC 偏移，旧录音缺少时区时注明回退。 |
| 健康页查缺失数据 | 可直接开启或刷新；区分未启用、无可读样本、查询失败与单指标缺失。无样本时提示核对健康数据来源、设备同步和读取权限。 |
