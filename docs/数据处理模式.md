# 数据处理模式

手机设置中的「数据处理」与「录音存储」独立。旧设置自动迁移为手机处理；自动每日分析开关仍独立，默认关闭。

| 处理方式 | 模型请求发生在哪端 | 结果与原音 |
| --- | --- | --- |
| 在 Watch 上处理 | Watch 通过 URLSession 调用手机所配置的方舟模型 | 纪要、原始语音时间窗口回传手机；手机只做本地健康关联和日报归档 |
| 在手机上处理（默认） | iPhone | 沿用分段、压缩、静音检测、重试和日报归档 |
| 不处理，导出到 Mac | 两端都不调用模型 | 停止日处理及其最终清理；原音继续按独立存储设置同步，用户下载后自行处理 |

切换控制尚未完成的工作。已保存的完整模型结果会被复用。切换手机端设置会取消本机进行中的请求；手表必须收到配对配置后才能生效，离线手表无法立即获知变化。

## Watch 配置与执行

在手机保存 API Key、选择模型后，选择 Watch 处理。首次处理时保持两端 App 打开并可达，以便同步凭据。公开配置包含处理方式、模型、随机版本号、自动／充电／网络／音频偏好，不含 Key 或由 Key 计算的摘要。Key 只通过配对的即时请求回复交付，随后保存在 Watch 本机钥匙串；不会写入 applicationContext、录音 JSON、云端或导出。

缓存凭据只匹配一个公开配置版本。配置变化后，手表等待重新同步，不能继续使用旧版本凭据。401／403 等鉴权失败等待配置变化；其他错误保存递增重试冷却。

自动任务处理已经结束日期的录音，遵守充电、低电量和热状态条件；上传请求按设置禁用蜂窝、高成本和受限网络。网络由 watchOS 决定，也可能经配对 iPhone 代理，不能承诺手表自身直连 Wi-Fi。手动处理会上传录音到同一模型服务，不受自动充电／网络偏好约束；录音期间两者都暂停。

Watch 复用手机的音频处理代码：保守静音检测、最多两分钟／4 MiB 解码负载分段、M4A／WAV 选择、源时间映射和持久化检查点。无需为处理启动训练或保持录音会话。后台时间不足时暂停，系统刷新或下次打开可继续，不保证一次在后台完成长录音。

## 存储组合

- 优先手表：直接处理手表原音。手机可接收结果后生成日报；手动同步仍可取回原音。
- 优先手机：批量传输与手机确认仍有效，但手表自身处理未完成时暂不释放原音。若旧录音已仅存在手机，手机会向 Watch 交付原音，持久化接收确认以免每次重传。返送副本保留到 Watch 完成或手机完成日报清理，也可手动删除，避免文件先于配置到达就被释放。手动请求按配置版本保存，乱序或过期请求不能授权其他版本的模型调用。
- 优先云端：上传确认先保存。只有 Watch 不再需要原音时，才释放手表副本；手机可从云端读取。处理失败仍保留原音。
- 不处理：存储／备份授权仍生效。手机和手表之间释放已确认的冗余副本不等于删除所有原音；不会因生成日报而做最终清理。需要永久保留在 Mac 的数据请完成下载并自行备份。

Watch 完成结果使用不可变 outbox，先落盘后回传；手机原子入库成功后才确认。重复投递不重新分析，晚到结果不会复活已清理的录音。仅收到结果时，手机明确标记没有本地音频，也可完成健康关联与归档；若还需要备份而原音未到，则保留待处理状态。

## Mac 导出

手机设置 →「Mac 临时下载」。先同步录音，再开启临时 HTTPS 服务。Mac 与手机需在同一 Wi-Fi；默认空闲 10 分钟关闭，可配置 1–60 分钟。受 watchOS 限制，网页下载由 iPhone 中转。

网页提供逐段 M4A 原音与 `WristJournal-metadata.json`。元数据格式版本为 1，包含：

- 录音 UUID、UTC 起止、录制时区、时长、状态、备注和粗略地点；
- 已保存的运动窗口、已有健康报告和日报；
- 对应音频文件名，以及本机是否确有可下载原音。

JSON 日期采用 ISO-8601。缺失的健康样本不补造，也不把系统 HealthKit 全量原始样本当作已导出内容。元数据下载需要同一临时凭证；导出不触发删除，不包含 API 配置或密钥。录音 CSV 也补充时区、地点与本地音频状态。

## 验证边界

核心回归覆盖默认迁移、路由、结果完整性、outbox 与 ACK 重启恢复、仅结果入库和清理后晚到去重。Debug 模拟器用合成音频执行 Watch 的真实 AVFoundation 编码与模型请求构造，模拟模型响应，再把 Watch 序列化结果交给手机日处理链路，验证没有手机二次请求。

模型网络响应是 fixture；模拟器间的测试结果交付由脚本完成，不能替代配对真机 WatchConnectivity 验收。上线前需在配对设备验证：首次 Key 同步、离线修改模式／Key、自动处理跨日唤醒、开始录音取消、后台到期恢复、Phone→Watch 原音传输、结果 ACK 丢失／重启、三种存储组合，以及真实方舟账户／模型权限。
